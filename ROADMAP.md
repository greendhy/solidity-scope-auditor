# Roadmap

## v0.1

- Dependency-free Solidity repository scanner
- Markdown scope report
- Detector signals for access control, external calls, token transfers, oracle usage, flash loans, liquidation logic, upgrades, and emergency controls
- Node.js test coverage

## v0.2

- JSON output mode for CI pipelines
- Severity hints for review signals
- More examples for Foundry and Hardhat projects
- Better detector grouping by contract

## v0.3

- GitHub Actions example workflow
- Optional report diffing between releases
- Maintainer checklist generated from detected hotspots

## Longer Term

- AI-assisted explanation layer for generated reports
- Issue triage templates for security review findings
- Public sample corpus for detector validation
